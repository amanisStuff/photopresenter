# Documentation Overview

This repository ships with lightweight, living documentation to help developers understand and contribute to PhotoPresenter.

- Core docs: HELP.md, DEVELOPERS.md, FEATURES.md
- Architecture and data flow: AGENT_CONTEXT.md (internal guidance for AI agents)
- How to run, test, and build: guidance embedded across README.md and dedicated sections in HELP.md and DEVELOPERS.md

Where to start:
- Read the root README.md for a quick project overview and getting started.
- Inspect HELP.md for user-facing help topics, feature notes, and reference tables (state, settings, shortcuts).
- Review FEATURES.md for a catalog of current features and capabilities.
- Check DEVELOPERS.md for setup, project structure, architecture, and contribution process.

If you want to add or update docs, create or edit files under this docs/ directory and reference them from the root README.
