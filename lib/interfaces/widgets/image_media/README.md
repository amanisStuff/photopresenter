# Image & Media

Everything related to loading, browsing, and displaying slide images.

- **ImageGrid** — the scrollable thumbnail browser showing all loaded images. Supports drag-and-drop reordering and delete.
- **ImageDisplay** — the main presenter area that renders the current slide at full size with animated transitions and real-time image filters.
- **AddImageCard** — a clickable "+" placeholder shown in the grid when there's room for more images.
- **GridImage** — an individual draggable thumbnail tile inside the grid with lazy loading and error handling.
