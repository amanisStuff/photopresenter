# Controls

Buttons, toggles, and toolbars that drive the slideshow.

- **PresentationControls** — the main command center (~1200 lines). Play, pause, stop, skip, save/load galleries, toggle fullscreen, scatter images, select image filters, enter class mode, and open settings — all in one silver bar.
- **AudioModeToggle** — a quick toolbar switch to flip between audio-driven and timer-driven progression.
- **ClassModeButton** — a pill-shaped toggle to start or stop a class session.
- **TimerAdjustment** — a dropdown to pick the slide duration (in seconds) for timer mode.
- **SilverIconButton**, **MenuButton**, **SilverPopupButton** — reusable building blocks used to give all control-bar buttons their consistent retro-silver look.
