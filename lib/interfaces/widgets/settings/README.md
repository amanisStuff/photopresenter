# Settings

UI elements that appear on the Settings screen for configuring the app.

- **AudioModeTile** — a radio-button list to choose between Timer-Driven and Audio-Driven slideshow modes.
- **ClassPresetTile** — displays a saved class preset's configuration summary with edit and delete actions.
- **SettingsTile** — a reusable row component (title + subtitle + trailing widget) used as the consistent building block across the settings screen.
