# Dialogs

Modal dialogs for configuration and file operations.

- **ClassModeSelectionDialog** — the main dialog for launching a class session. Lets you pick a saved preset or configure warm-up, early, mid, and final phase counts along with break settings.
- **EditPresetDialog** — a form for creating or renaming class presets. Uses stepper controls for each phase duration and a toggle for auto-break.
- **LoadGalleryDialog** — lists previously saved galleries so you can reload one into the presentation.
