# Common

Small reusable widgets shared across screens and features.

- **CustomTitleBar** — the window chrome at the top with drag-to-move, app title, and minimize/maximize/close buttons.
- **RetroSwitch** — a custom toggle switch styled to look like a retro rocker switch with raised/lowered halves.
- **NumberInputRow** — a labeled row with decrement/increment buttons and a centered number readout, used in the preset editor.
- **SectionHeader** — a simple title with a colored divider line beneath, used to label sections on the settings screen.
