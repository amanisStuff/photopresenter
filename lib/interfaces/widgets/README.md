# interfaces/widgets/

Composable UI components organised by concern. No business logic — only presentation.

- `common/` — Small reusable widgets (title bar, toggle switch, stepper, section header)
- `controls/` — Toolbar buttons, toggles, and the main control bar
- `dialogs/` — Modal dialogs for class session setup, preset editing, and gallery loading
- `image_media/` — Image grid, thumbnail cards, and the full-size display with filters
- `overlays/` — Full-screen layers for breaks, countdown timers, phase badges, and 3D viewport
- `settings/` — Settings tiles for audio mode, class presets, and reusable row component
