# Overlays

Full-screen layers that sit on top of the presentation to show status or provide temporary info.

- **BreakOverlay** — shown during a class-mode break. Displays remaining break time with a resume button.
- **FocusTimerOverlay** — a slim countdown bar at the bottom of the screen for the current timer-driven slide.
- **ClassPhaseIndicator** — a small color-coded badge (Warm-Up, Early Study, etc.) that tells you which class phase is active.
- **Viewport3D** — an animated 3D cube screensaver that appears when no images are loaded.
