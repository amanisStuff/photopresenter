# photopresenter

PhotoPresenter: a cross-platform desktop image slideshow application built with Flutter.

## Getting Started

This project is a cross-platform Flutter desktop application for presenting images as slideshows with optional audio and a focus/class-mode workflow.

A few resources to get you started if this is your first Flutter project:

- [Lab: Write your first Flutter app](https://docs.flutter.dev/get-started/codelab)
- [Cookbook: Useful Flutter samples](https://docs.flutter.dev/cookbook)

For help getting started with Flutter development, view the
[online documentation](https://docs.flutter.dev/), which offers tutorials,
samples, guidance on mobile development, and a full API reference.

- Features include: image slideshow with timer or audio-driven transitions, focus mode, and class mode for figure drawing practice.
- Image filters (Black & White, Sepia) are available via the Presentation Controls (palette icon). See FEATURES.md for details.
- Documentation: HELP.md, FEATURES.md, and DEVELOPERS.md describe the project and how to contribute.

- Documentation: See docs/README.md for an overview of the repository's documentation and how to navigate the docs.
