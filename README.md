# photopresenter

PhotoPresenter: a cross-platform desktop image slideshow application built with Flutter.
- Features include: image slideshow with timer or audio-driven transitions, focus mode, class mode for figure drawing practice, and 9 image filters.
- Documentation: HELP.md, FEATURES.md, and DEVELOPERS.md describe the project and how to contribute.
- See docs/README.md for an overview of the repository's documentation structure.
