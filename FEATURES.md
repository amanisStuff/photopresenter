New Feature: Image Filters (Black & White, Sepia)
- Filters available: Black & White (bw) and Sepia.
- You can cycle None -> BW -> Sepia -> None from the Presentation Controls bar (Filter icon).
- Rendering uses ColorFiltered with calibrated matrices; the source image data is unchanged.
- This is a per-session UI feature and currently not persisted across restarts unless extended.
